# 细胞花园 · Windows 动态桌面壁纸

双击 **CellularGarden.exe** 即可运行。纯本机程序，不需要浏览器、服务器、网络连接、Wallpaper Engine 或 Lively。适用于 Windows 10 / 11 x64，使用系统自带的 .NET Framework 4.x。

## 日常使用

- 默认在选中的显示器上，挂在桌面图标后方自动演化。图标、桌面菜单仍由 Windows 处理。
- **双击托盘中的绿色细胞图标**，或按 **Ctrl+Alt+G**，进入控制模式。图标可能收在任务栏的隐藏图标菜单中。
- 也可以再次双击 EXE；已有实例会打开控制面板，不会重复运行。
- **Esc / 返回壁纸** 关闭控制模式，保留当前播放状态。若先暂停，再返回，壁纸仍保持暂停。
- **Ctrl+Alt+Space** 在任何应用中切换播放 / 暂停；如果快捷键被其他程序占用，可用托盘菜单。
- 托盘右键 → **退出细胞花园** 完全退出，露出原有系统壁纸。

## 控制模式

| 操作 | 方法 |
| --- | --- |
| 绘制 / 擦除 | 选择画笔或橡皮，左键拖动。绘制自动暂停，松开后作为新的初始状态 |
| 平移画面 | 右键或中键拖动；也可选择“移动”后左键拖动 |
| 缩放 | 滚轮或 ＋ / －；“视角归位”恢复居中、100% |
| 移动面板 | 拖动固定在顶部的标题栏；设置滚动后标题栏仍可操作 |
| 收起面板 | 画布获焦时按 Tab；再次 Tab 展开。输入框中的 Tab 正常切换焦点 |
| 播放 / 暂停 | 面板按钮或空格 |
| 下一代 | 面板按钮或 N |
| 重置 | 面板按钮或 R，恢复最近一次播种 / 绘制后的初始状态并暂停 |
| 规则 | 康威生命游戏、HighLife、Seeds；切换从第 0 代重新记录 |
| 播种 | 四种预设、随机播种、清空。预设和清空会暂停，随机播种保留播放状态 |

演化速度可直接输入数值（支持小数），并选择“秒/代”或“代/秒”；按 Enter 或移开焦点生效，切换单位保持当前速度，设置自动保存。速度范围从每 60 秒一代到每秒 30 代。“显示网格”会为当前可见区域的每个方块（包括空白格）绘制独立细描边，方块之间保留间隙，描边明暗随背景调整。另支持循环边界、生命余迹、代数 / 种群 / 密度统计与最近 100 代趋势。可从“壁纸显示器”切换到其他已连接的显示器。当前版本一次显示在一块屏幕上。

随机播种覆盖当前可见画面：平移或缩放后点击“随机播种”，会清除上一批细胞，并按当前视野重新生成，保留当前视角和播放状态。网格范围自动随本次播种调整，控制面板覆盖的位置也属于画布。后台自动播种同样使用当前壁纸视野。预设图案仍采用居中的 160 × 90 网格；循环边界作用于当前这一批模拟区域。移动本身不会自动生成新细胞；移出旧区域后仍可直接绘制，落笔时网格扩展至整个可见画面，并保留已有细胞。Tab 收起面板后可绘制原先被面板遮挡的位置。循环边界随扩展后的网格变化。

## 主题与长期运行

控制面板区域会阻挡画笔、橡皮、平移和画布缩放；即使按住鼠标从画布划过面板，也不会画到面板后方。将面板移开即可绘制原位置。面板内保留普通指针和文字输入光标，标题栏使用移动光标。编辑数值后会短暂合并连续修改并在后台保存，退出时等待最新设置写入。

点击控制面板上方的 **外观个性化 · 纯色 / 图片**：

- **纯色模式**：分别选择细胞颜色和背景颜色。打开选色器即可选色或输入 RGB 值。
- **图片模式**：导入 PNG、JPG、BMP 或 GIF（第一帧）。图片按屏幕居中裁切铺满，固定在屏幕上，不跟随画布平移或缩放。活细胞显露图片对应的方格；死亡余迹最多以 45% 不透明度叠加清晰图片，逐代淡回背景；空白位置以约 12% 不透明度显示模糊底图，呈现毛玻璃效果。关闭“生命余迹”后，死细胞立即回到毛玻璃背景。清晰和模糊底图均固定在屏幕上，模糊缓存仅在图片、屏幕尺寸或底色改变时重建。
- 导入图片时会分别提取亮色、暗色主题的推荐底色，优先采用图片中的亮色 / 暗色。如果没有合适的颜色，会从图片平均色派生浅色 / 深色。底色可手调，“使用推荐底色”恢复当前主题的自动配色。
- 亮暗两套纯色配色和图片底色分别记忆。导入新图片会重新推荐两套底色。切换外观不改变当前细胞、相机或播放状态。
- 图片只保存在本机程序目录的 `wallpaper-image.png`，不会上传。导入后原文件可移动；重启仍可使用。图片最长边会限制为 4096 像素，超过 8000 万像素的原图请先缩小。移动程序时请连同 `settings.json` 和 `wallpaper-image.png` 一起移动。

- 主题有 **跟随系统 / 亮色 / 暗色**。自动模式每 2 秒读取 Windows 的“Windows 模式”亮暗设置，面板与壁纸同步更新。控制窗口、按钮和外观对话框使用当前壁纸底色与强调色，文字自动调整对比度。
- “自动播种”分为两个独立开关：**静止 / 重复后播种**（默认持续 30 秒，可设 1–3600 秒）和 **定时重新播种**（默认每 5 分钟，可设 1–1440 分钟）。任一启用条件满足即更新，并重新计时。旧版开关状态会保留为两项初始状态。只累计壁纸正在演化的时间，暂停、锁屏、全屏暂停、控制模式均不计时；等待时间不受演化速度影响。静止 / 重复指最近 32 代内出现重复状态，检测需要先演化出重复帧；慢速时也一样。
- 锁屏或系统挂起时暂停计时，恢复后继续；默认在目标显示器有全屏应用时暂停，可以取消勾选。
- 程序每 10 秒及退出控制模式时保存当前细胞、初始图案、速度、主题、视角和播放状态至旁边的 `settings.json`。退出再打开会延续该状态。
- 不自动添加开机启动。如需随登录启动，可以把此 EXE 的快捷方式放入当前用户的 Windows“启动”文件夹。

## 恢复与限制

Windows 没有正式公开的动态壁纸嵌入 API；本程序兼容传统 WorkerW 和新版 Windows 的分层桌面结构。若资源管理器或系统更新改变桌面层级，程序会尝试重新连接，也可从托盘点击“重新连接桌面”。连接失败会保留控制模式预览，不覆盖普通窗口。

运行期间不要移动程序目录。多屏切换、不同 DPI 的显示器热插拔及其他壁纸软件同时运行尚未全面实机验证。Windows 更新后若无法挂载，请先从托盘重连或退出再运行。

## 开发与验证

源码位于同目录的 `*.cs`，原网页版位于上一级 `dist/`。

```powershell
./build.ps1
./CellularGarden.exe --self-test
```

`test-results.txt` 包含算法、绘制、重置、视野播种、有限历史、配置恢复等断言和演化耗时。`--preview` 仅显示预览；`--control` 启动壁纸并打开控制模式。

`desktop-status.json` 是本机诊断数据，记录桌面连接、播放、主题、控制模式和演化状态；不上传任何数据。出现错误时会生成 `error.log`。

实现参考：[Microsoft SetParent 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setparent)、[Lively 项目关于 Windows 11 桌面层级的讨论](https://github.com/lively-community/lively/issues/2074)。
